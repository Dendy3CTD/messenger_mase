# legacy: версия 0.2 (не поддерживается)

Здесь лежит первая версия mase: сервер на C++ (`cpp-server/`), TCP-протокол на порту 5555, вход по одноразовому коду (OTP), обнаружение сервера в локальной сети через mDNS и графические скрипты управления сервером.

Она **не совместима** с текущим приложением и текущим Go-сервером (`go-server/`, WebSocket, вход по телефону и паролю) и хранится только как история. Текущая версия описана в корневом `README.md`.
